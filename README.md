# Lumen AI v1.6

AI 글쓰기 웹앱의 UI와 사용성을 개선한 버전입니다.

## 이번 버전 변경 사항
- 모바일/PC 레이아웃 및 시각 계층 개선
- 문체 선택 5종 추가
- 글 분량 선택 추가
- 빠른 예시 요청 버튼 추가
- 입력 내용 자동 임시 저장
- 결과 글자/단어 수 표시
- TXT 파일 저장 기능
- Ctrl/Cmd + Enter 단축키
- PWA 앱 설치 버튼
- 서비스 워커 캐시 갱신 및 깨진 로고 경로 제거
- 서버 입력 길이 검증 추가

## 배포
Vercel 프로젝트에 전체 파일을 업로드하고 `OPENAI_API_KEY` 환경 변수를 유지하세요.
선택적으로 `OPENAI_MODEL`을 설정할 수 있습니다. 기본값은 `gpt-5-mini`입니다.

## v1.6 — History & Editing
- 최근 작성 결과 로컬 이력 저장 (최대 50개)
- 작성 이력 열기 / 개별 삭제 / 전체 삭제
- 결과 직접 편집 및 자동 저장
- 원본 복원
- 빠른 AI 재작성 버튼
- 오프라인/입력 검증 및 오류 안내 개선
- 모바일 결과 편집 UI 개선
